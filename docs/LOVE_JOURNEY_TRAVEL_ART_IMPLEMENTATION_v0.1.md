- 不影响范围：旅行状态机、收尾拼图、密码与信封场景、其他关卡

## 1. 实施结论

场景 4 已从黑白 CSS 线稿替换为蓝白手绘正式美术，同时保留原有玩法与可访问性入口：

1. 房间背景、两位旅行者和浅蓝互动面板构成完整竖屏场景。
2. 打开的行李箱使用独立箱盖与箱体分层，支持真实合箱动画。
3. 相机、帽子、车票和充电器使用透明 PNG，收纳后平滑移入箱体内部。
4. 四件物品收齐后，上滑提示显示在箱盖空白区，不遮挡已收纳物品。
5. 合箱末段切换至独立闭箱成品素材，保留明确的动画落点后再进入收尾拼图。
6. 人物、面板、行李箱和四件物品统一映射到 `travel-packing-keyframe.png` 的 1080 × 1920 设计坐标，画板裁切时仍保持彼此相对位置。
7. 移除顶部操作说明与画面中部收纳状态文本，只在物品收齐后保留可操作的“上滑合箱”入口。

## 3. 画面与交互分层

场景由后到前使用以下层级：

```text
房间背景
→ 左右旅行者
→ 浅蓝互动面板
→ 行李箱箱盖与箱体
→ 可拖动物品
→ 标题与合箱操作入口
```

物品拖动期间提升至最高交互层；收纳后缩小并进入箱体内部的固定位置。开箱和闭箱素材使用交叉淡入淡出，避免将已绘制好的透视素材强行拉伸。

## 4. 玩法与兼容性

现有状态机保持不变：

```text
packing -> ready-to-close -> closing -> completed
```

- 支持拖动物品到箱体内部。
- 支持点击或 Enter/Space 自动收纳。
- 支持向上滑动、点击或 Enter/Space 合箱。
- 聚焦态使用黄色高对比描边。
- `prefers-reduced-motion` 下跳过长动画，但仍完成状态切换。
- 普通动画下闭箱节奏为 720ms，确保闭箱成品有可见落点。
